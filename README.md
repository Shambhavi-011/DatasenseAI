> **AI-powered data analytics platform that lets you explore, analyze, and interact with your datasets using natural language.**

DataSense AI is a full-stack AI-powered analytics platform that transforms raw CSV datasets into meaningful insights through automated data analysis, visualizations, and natural-language queries.

Instead of manually writing SQL queries, users can simply ask questions about their uploaded dataset and receive AI-generated results in the form of answers, tables, and visualizations.

## ✨ Features

### 📁 Upload & Explore Datasets
- Upload CSV datasets
- Automatic dataset processing
- Dataset preview
- Dynamic column detection
- Works with different types of datasets

### 🤖 Ask Your Data

Ask questions about your dataset using natural language.

Examples:

```text
How many rows are in this dataset?

Which region has the highest revenue?

Show total sales by product.

What is the average value?

Which category has the highest count?
```
